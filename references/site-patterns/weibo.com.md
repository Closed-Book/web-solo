# weibo.com

实测日期：2026-09-22

**这是登录墙，不是反爬拦截。** 两者的处理方式相反，先分清再动手。

| 档位 | 结果 |
|---|---|
| 第 1 档 headless | ❌ 0 字符，title 为 `Sina Visitor System` |
| 第 2 档 有头 + `--unblock 20000` | ⚠️ 272 字符，title 为空——**实质没过**，拿到的不是正文 |

- **模式**：未登录状态下没有能用的档位。要内容就得带登录态。
- **参数**：先按 `SKILL.md`「登录态」一节有头登录一次，之后：

  ```bash
  python3 scripts/browser.py fetch https://weibo.com/ --profile ~/.web-solo-profiles/weibo
  ```

  （带登录态的代价见 `SKILL.md`：凭据交给工具、目录自己保管、有账号风控风险。）

- **正文选择器**：未登录状态下没有正文可取。带登录态后的选择器**尚未实测**，不要照抄别处的猜测。
- **要等什么**：不适用——问题不在等待时长上。
- **坑**：
  - `Sina Visitor System` 是微博的**访客系统**，意思是"它不打算给游客看"，不是"它认出你是机器人"。加 `--headed`、换 UA、加长 `--unblock` 一概没用，别往那个方向试。
  - 第 2 档那 272 字符最容易骗人：`text_len` 不是 0，看着像过了一半，其实 `title` 是空的、内容也不是正文。**判据要看 title 和内容本身，不要只看 text_len 大于 0。**
